# Treasure Island

🌐 **English**

A beginner-friendly Python "Choose Your Own Adventure" text game: you pick your
way through a short story, and your choices decide whether you find the
treasure. It is part of Udemy's *100 Days of Code: The Complete Python Pro
Bootcamp* and has no runtime dependencies.

| Page | Read it when you want to |
| --- | --- |
| [How to Play](How-to-Play) | Learn the story, the choices and the one winning path |
| [Install](Install) | Set up Python, create a virtual environment and start the game |
| [Development](Development) | Understand how the code is built, change the story and run the tests |

## At a glance

```text
src/treasure_island/   the game (game.py) and its entry point (__main__.py)
tests/                 pytest tests for every path through the story
pyproject.toml         package metadata, the treasure-island command and pytest settings
docs/                  project documents and this wiki (docs/wiki/)
framework/             the SQA and QC framework, a pinned submodule
```

## Requirements

- Python 3.13 or newer
- `pytest` (only for running the tests)
